# ToonAnime 変更履歴

`ToonAnime_6.fxdayo` から `ToonAnime_28.fxdayo` まで、対象フォルダに現存する版をファイル更新日時順（同時にバージョン番号順）で整理した。

> 注記
>
> - `ToonAnime_7.fxdayo`、`ToonAnime_8.fxdayo`、`ToonAnime_10.fxdayo` は対象フォルダに存在しないため、個別の変更内容は確認できない。
> - `ToonAnime_9.fxdayo` はファイル内の記述では `ToonAnime_8.fxdayo` ベース、`ToonAnime_11.fxdayo` は `ToonAnime_9.fxdayo` ベースである。
> - `ToonAnime_mob_01.fxdayo` は連番版ではないため、この履歴の対象外とした。

## 2026-03-25 — ToonAnime_6.fxdayo

- `Preview.fxdayo` 系をベースに、バックフェース拡張法によるシルエット用 `Edge` パスを追加。
- `MMD` パスを、シャープな明暗境界と濃い影色を持つアニメ調トゥーンシェーディングへ変更。
- `Edge` パスで作った深度を保持するため、後続の `MMD` パスでは Z バッファをクリアしない構成に変更。
- 透明・半透明マテリアルはエッジ描画から除外。
- ポストプロセスの FXAA を追加。

※ ファイル内の版名コメントは `ToonAnime_5.fxdayo` となっているが、本履歴では実ファイル名の `ToonAnime_6.fxdayo` として扱う。

## 2026-03-29 — ToonAnime_9.fxdayo

- 影をライト・1号影・2号影の3領域に分ける、2段階アニメ影を実装。
- Toon テクスチャありの場合は、`NoL` に応じて明・中間・暗の3行を離散的にサンプリング。
- 共有 Toon／Toon テクスチャなしの場合は、ライト `1.0`、1号影 `0.65`、2号影 `0.35` の明度倍率で階層化。
- `SHADOW_SMOOTH` を導入し、影境界をわずかにぼかしてジャギーを抑制。
- `ToonAnime_6` との現存ファイル間比較では、レイトレーシング AO の `RTAO` パス、AO 用 UAV、ポイントサンプラ、AO の最終合成も追加されている。これらが欠番の `7`／`8` のどの段階で導入されたかは特定できない。
- パス順を `GBuffer → Edge → MMD → RTAO → Copy → DENOISE → FXAA` に再構成。

## 2026-03-30 — ToonAnime_11.fxdayo

- `RTAO` の名称を `SSAO` に統一。実装はレイトレーシング AO のまま。
- HDR Bloom を追加。高輝度領域の抽出、水平・垂直のセパラブルガウスブラー、最終加算合成を実装。
- FXAA を高品質化。9点輝度サンプリング、サブピクセル AA、広域エッジ探索を追加し、SSAO・Bloom 合成済みの `RTOutput` を入力に変更。
- `edgeSize >= 1.0` の材質は固有の `edgeColor`、`edgeSize < 1.0` の材質は薄い灰色 `EDGE_GRAY` を使用するようにエッジ描画を分岐。

## 2026-03-30 — ToonAnime_12.fxdayo

- Bloom の発光検出を単純な画面輝度しきい値方式から AutoLuminous 互換の材質判定方式へ変更。
- `GBuffer1`／`GBuffer2` からモデル番号、面番号、重心座標を復元し、`MMDMaterials`、`IB`、`VB` を参照して材質と UV を再構築。
- 「スペキュラ色が黒に近い」かつ「`shininess >= 100`」を発光条件とし、モーフ適用後の材質値を判定に使用。
- 発光色を `diffuse + ambient` とテクスチャから算出するよう変更。

## 2026-03-30 — ToonAnime_13.fxdayo

- 発光色の生成をポストプロセス側での材質再構築から、`GBuffer` ラスタライズ時に `MyEmissive` RTVへ直接書き出す方式へ刷新。
- `Copy` パスで `MyEmissive` を `EmissiveBuf` UAVへ移し、後続の Bloom 抽出で使用する構成に変更。
- 発光判定を一時的に「スペキュラ色が黒ではない材質」へ変更。
- 発光色を `specular.rgb × BLOOM_EMISSIVE_MULT` とし、テクスチャがある場合はその色を乗算。

## 2026-03-30 — ToonAnime_14.fxdayo

- `ToonAnime_13` の発光バッファ構成を維持しつつ、発光判定を AutoLuminous 互換方式へ戻した。
- 発光条件を「スペキュラ色が黒に近い」かつ「`shininess >= 100`」へ変更。
- 発光色を材質本来の `diffuse + ambient` とテクスチャから算出。
- 発光強度を `(shininess - 100) / 10` で算出し、`shininess=110` を標準強度 `1.0` とした。

## 2026-04-01 — ToonAnime_15.fxdayo

- `NormalDepth.w` に `SV_POSITION.w` ではなく、`ViewMatrix` から求めた真のビュー空間 Z 距離 `viewZ` を格納。SSAO のワールド位置再構築精度を改善。
- 発光色の計算と `MyEmissive` への出力をアルファ破棄より前へ移動し、半透明発光の取りこぼしを抑制。
- Bloom を強化。`BLOOM_INTENSITY` を `0.40 → 0.60`、`BLOOM_SIGMA` を `2.5 → 4.0`、`BLOOM_RADIUS` を `5 → 8` に変更。

## 2026-04-01 — ToonAnime_16.fxdayo

- フレネル効果を利用したアニメ調リムライトを追加。
- 法線と視線方向からシルエット付近を抽出し、`RIM_POWER` と `smoothstep` によって細さと境界の硬さを制御。
- リム色、強度、開始しきい値、ぼかし幅、影領域での減衰をパラメータ化。

## 2026-04-03 — ToonAnime_17.fxdayo

- `ToonAnime_16` ではなく `ToonAnime_15` をベースに再構成したため、`16` で追加されたリムライトは継承していない。
- AutoLuminousSetter 互換の頂点発光方式を追加。追加 UV 1～3を頂点シェーダで受け取り、識別コード、発光色・強度、点滅周期・位相、テクスチャモード、HSV モードを処理。
- 従来の材質発光方式と頂点発光方式を併用し、頂点発光を優先判定。
- 発光強度の上限を `1.0` から `AL_MAX_OVERBRIGHT` まで拡張し、HDR のオーバーブライトを許可。
- Bloom をタイト層とワイド層のデュアルレイヤー構成へ変更し、鋭いコロナと広い光の靄を別々に生成・合成。

## 2026-04-03 — ToonAnime_18.fxdayo

- 材質発光強度の式を一旦 `(shininess - 100) / 10 + 1` に変更し、`shininess=100` でも強度 `1.0` で発光するよう修正。
- `MMD` パスでも `CalcAutoLuminous` を呼び、半透明材質の発光を `EmissiveBuf` UAVへ直接出力。
- `Copy` パスによる `EmissiveBuf` の無条件上書きを `max` 合成へ変更し、`MMD` パスで書いた半透明発光を保持。

## 2026-04-04 — ToonAnime_19.fxdayo

- 頂点発光のテクスチャモード `texMode == 2` を実装。テクスチャ輝度に `smoothstep(0.4, 0.6, luma)` を適用し、明るい部分だけを発光。
- 複数の半透明発光レイヤーが互いを上書きしないよう、`MMD` パスの `EmissiveBuf` 書き込みも成分ごとの `max` 合成へ変更。
- `CalcAutoLuminous` 内でグローバルな `ModelIndex` を再取得していた冗長処理を削除し、関数引数のモデル番号を一貫して使用。
- 追加 UV 3 の `exuv3.z` によるポップアップ機能を実装し、モーフによる即時点灯時は点滅計算を無効化。

## 2026-04-04 — ToonAnime_20.fxdayo

- フレーム開始時に `EmissiveBuf` をゼロクリアし、前フレームの発光が残ることによる残像やポリゴン貫通を修正。
- 発光強度を AutoLuminous 公式仕様に合わせて `(shininess - 100) / 10` へ戻し、`shininess=100` を発光下限 `0.0`、`110` を標準強度 `1.0` とした。

## 2026-04-05 — ToonAnime_21.fxdayo

- AutoLuminous 判定、発光バッファ、Bloom の生成・合成処理をレンダラから分離。
- 発光と Bloom は外部ポストプロセス `PPAL.fxdayo` が担当する構成へ変更。
- ToonAnime 側は `GBuffer1`、`GBuffer2`、`NormalDepth` を出力し、PPAL がモデル・面・UVを再構築できるベースレンダラに整理。
- 発光専用テクスチャ、UAV、Bloom 各パスを削除し、描画パイプラインを簡素化。

## 2026-05-18 — ToonAnime_22.fxdayo

- PNG テクスチャのアルファ値を RGB の乗算・加算処理から独立して保持し、明示的に扱うよう変更。
- `TEX_ALPHA_CUT` を導入し、完全透過に近いテクセルを早期 `discard`。
- スフィアマップの加算モードではアルファを乗算せず、乗算モードだけ控えめに反映してアルファ破壊を防止。
- `0.98` 以上のアルファを `1.0` に丸める旧処理を廃止し、連続的な半透明階調を維持。
- `GBuffer` のカリングではテクスチャ単独のアルファを主基準、材質合算アルファを補助基準に変更。

## 2026-05-20 — ToonAnime_23.fxdayo

- PNG 透過部分が黒く塗り潰される原因だった `Edge` パスを修正。
- PMX 材質のエッジ描画フラグ（`drawFlag` bit 4）を尊重し、エッジ無効材質を `discard`。
- `Edge` パスでも拡散テクスチャのアルファをサンプルし、透明テクセルを `discard`。
- `ToonAnime_22` の PNG アルファ明示処理は維持。

## 2026-05-21 — ToonAnime_24.fxdayo

- MMD のブレンドをストレートアルファから前乗算アルファへ変更（`srcBlend: src_alpha → one`）。
- 通常材質はシェーダ出力 RGB にアルファを前乗算し、従来と同等の通常アルファ合成を維持。
- AutoLuminous 発光材質はカバレッジを RGB に前乗算し、出力アルファを `0` にして純加算合成。
- 半透明発光スプライトが重なるたびに背景を減衰させて黒くなる問題を解消。

## 2026-05-24 — ToonAnime_25.fxdayo

- 発光ジオメトリを通常の `MMD` パスから分離し、専用の `MMDAdd` パスを追加。
- `MMD` パスでは不透明・非発光材質を深度書き込みありで描画。
- `MMDAdd` パスでは発光材質のみを、深度テストあり・深度書き込みなし・加算合成で描画。
- 同一 PMX 内で交差する半透明発光プレーンが互いの深度で切り取られる問題を修正。

## 2026-05-25 — ToonAnime_26.fxdayo

- `MMDAdd` を `MMDTrans` に再編し、不透明ピクセルと、それ以外の半透明／発光ピクセルを最終アルファで振り分ける構成へ変更。
- `MMD` パスは `最終α >= OPAQUE_CUT` の非発光ピクセルだけを描画し、深度を書き込む。
- `MMDTrans` パスは非発光半透明と発光材質を描画し、深度を書き込まない。
- アルファマスクの不透明部分だけが深度を書き、ソフトな半透明部分は深度を書かないピクセル単位判定を導入。
- 非発光の半透明サーフェスが先に深度を書き、その背後の発光ビームを消してしまう回帰を修正。

## 2026-06-10 — ToonAnime_27.fxdayo

- AutoLuminous 判定された材質を、最終発光カバレッジ `emitCover` によって「不透明発光」と「半透明発光」に分離。
- 不透明発光は `MMD` パスで、前乗算アルファ `1`・深度書き込みありの遮蔽する通常合成として描画。
- 半透明発光は `MMDTrans` パスで、アルファ `0`・深度書き込みなしの純加算合成として描画。
- 目材質などが AutoLuminous 材質と誤判定された際に、白飛びしたり背後が透けたりする `ToonAnime_26` の回帰を修正。
- 交差する半透明発光、非発光半透明による遮蔽回避、ピクセル単位の不透明判定は維持。

## 2026-07-10 — ToonAnime_28.fxdayo

- アルファブレンドされる半透明ポリゴンを SSAO の対象面・遮蔽面から除外。
- `GBuffer` パスは `c.a >= OPAQUE_CUT` の不透明ピクセルだけを書き込むよう変更。
- SSAO の `AnyHit` で、材質アルファが `OPAQUE_CUT` 未満の三角形に `IgnoreHit()` を適用し、AO レイを遮蔽させないよう変更。
- 半透明面の合成後に適用される AO が、その背後の不透明キャラクターを不自然に暗くする「影」の発生を抑制。
- `ToonAnime_27` の不透明／半透明発光の振り分けと、目材質の発光・透過回帰修正は継承。

## 2026-07-18 — ToonAnime_29.fxdayo

- `ToonAnime_28` の描画コードと定数値を維持したまま、編集・保守用のコメントを整理。
- 「ユーザー変更可」「変更不可」「要コードレビュー」の境界を明記。
- 各処理へ `HOW`、`WHY NOT`、Codex向け覚書を追加し、パス間の契約と変更時の注意点を文書化。
- 描画順、透過・発光、GBuffer、SSAO、PPAL連携の確認項目をファイル末尾へ追加。

## 2026-07-25 — ToonAnime_30.fxdayo

- `ToonAnime_29` から `FXAA` ポストプロセスパスを削除し、最終描画順を `SSAO → Copy` までに変更。
- `FXAA_EDGE_THRESHOLD`、`FXAA_EDGE_THRESHOLD_MIN`、`FXAA_SUBPIX_QUALITY`、`FXAA_MAX_SPAN` の調整定数を削除。
- 周囲9画素の輝度差検出、エッジ方向推定、サブピクセル補正を行うFXAAシェーダー本体を削除。
- FXAAに関する説明と回帰確認項目を削除。輪郭線、2段階アニメ影、SSAO、透過・発光処理は29版から継承。

## 2026-07-25 — ToonAnime_31.fxdayo

- `ToonAnime_30` のユーザー変更可能な定義値を、`ToonAnime.pmx` の17個のモーフから調整する方式へ変更。
- 輪郭線6項目、2段階アニメ影8項目、SSAO 3項目を `[YRZFX]` の `controllers` と接続。
- PMXモーフ値をすべて `0`～`1` に統一し、負の影しきい値、AO半径、整数のAOサンプル数はHLSL側で実際の値域へ変換。
- 透明な最小構成のユーザー定義値コントローラー `ToonAnime.pmx` を追加。
- `ToonAnime_30` の定数値をフレーム0で復元する `initial.vmd` を追加。
- `AO_BIAS` など「要コードレビュー」の内部値はPMX制御の対象外とし、30版の値を維持。
