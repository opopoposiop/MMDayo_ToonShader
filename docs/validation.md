# 動作確認項目

このリポジトリにはシェーダーを自動コンパイルするテスト環境は含まれていません。公開前は、実際の MikuMikuDayo 環境で次を確認します。

- `ToonAnime_32.fxdayo` が読み込め、共有 HLSL を解決できる
- `ToonAnime.pmx` と `initial.vmd` を適用できる
- 不透明な目、肌、衣装が発光せず、背後を正しく隠す
- 半透明の髪、レース、ビームが奥の不透明物を必要以上に隠さない
- 交差する半透明発光面が黒くならず、深度で欠けない
- PNG の完全透明部に色、輪郭線、深度、AO の影が残らない
- 半透明ポリゴンが GBuffer や SSAO の遮蔽面にならない
- エッジ無効材質と発光材質に不要な輪郭線が出ない
- PPAL を併用する場合、発光判定と GBuffer の解釈が一致する
- 透視投影と平行投影の両方で背景と SSAO の位置が正しい

確認記録には、確認日、MikuMikuDayo の版、GPU・ドライバー、PPAL の版、使用した PMX/VMD を残します。
