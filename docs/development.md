# 開発メモ

## 現行構成

`ToonAnime_32.fxdayo` の描画順は次のとおりです。

```text
BG → GBuffer → Edge → MMD → MMDTrans → SSAO → Copy
```

- `GBuffer` は不透明ピクセルの法線、深度、モデル番号、面番号、重心座標を保存します。
- `MMD` は不透明面と不透明発光を描画し、深度を書き込みます。
- `MMDTrans` は通常の半透明面と半透明発光を描画し、深度を書き込みません。
- `SSAO` は不透明面を基準にレイトレーシングで遮蔽量を計算します。
- `Copy` は SSAO を適用し、PPAL が利用する GBuffer を転写します。

## 変更時の契約

半透明面を GBuffer や SSAO の遮蔽面へ登録すると、合成後の背後のモデルに不自然な暗さが出ます。通常の半透明と発光の合成方式、深度書き込み、`OPAQUE_CUT`、GBuffer のパッキングは一体で確認してください。

AutoLuminous 方式を参考にした発光材質判定は、通常描画と PPAL の Bloom 判定で一致している必要があります。片側だけ定数や判定条件を変更しないでください。

## 保守方針

- 見た目の調整は `ToonAnime.pmx` のモーフから行います。
- コードコメントは処理の逐語的な説明ではなく、制約と採用しなかった方法を記録します。
- 変更履歴には変更理由を記録します。
- `archive/` の過去版は、現行版の動作確認用コードとして扱わず、履歴資料として保持します。
